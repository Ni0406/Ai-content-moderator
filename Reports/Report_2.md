# Отчет по Серии Заданий 2: API, Тестирование и LLM-Агент

## 1. API для ИИ-модели (FastAPI)
Был разработан микросервис на базе фреймворка FastAPI. 
В качестве ИИ-модели использована `blanchefort/rubert-base-cased-sentiment` (анализ тональности текста). 
- Создан эндпоинт `/analyze`, принимающий JSON с текстом и возвращающий тональность и уверенность модели (confidence).
- Использована валидация входных данных с помощью `pydantic.BaseModel`.

## 2. Тестирование API (PyTest и CI/CD)
Для проверки работоспособности API были написаны unit-тесты с использованием `TestClient` из FastAPI.
- Покрыт успешный инференс (позитивный/негативный текст).
- Покрыта обработка ошибок (пустой текст возвращает 400 Bad Request).
- **CI/CD:** Настроен GitHub Actions. При каждом коммите в ветку поднимается контейнер Ubuntu, устанавливаются зависимости и автоматически прогоняются тесты, гарантируя стабильность билда.

## 3. API для LLM (Ollama)
Интегрирована локальная языковая модель.
- Развернут сервер Ollama для локального инференса на Apple Silicon (Metal API).
- Добавлен эндпоинт `/summarize` для краткой выжимки текстов с использованием LLM.

## 4. Оценка лёгких LLM-моделей
Был проведен анализ легковесных моделей (2B-8B параметров) для работы локально:
1. **Qwen-2.5 (1.5B):** Выбрана как основная. Отличная поддержка русского языка, хорошая агентность (следование системным промптам), потребление RAM ~1.6 ГБ.
2. **Phi-3 Mini (3.8B):** Хорошая логика, но хуже работает с русским языком.
3. **TinyLlama (1.1B):** Очень быстрая, но высокая склонность к галлюцинациям.

## 5. Создание AI-агента на основе LangChain
Вместо жесткой логики (if/else) реализован интеллектуальный маршрутизатор на базе `LangChain` (парадигма ReAct: Reason + Act).
- **Суть:** Пользователь пишет свободный текст, а LLM (Qwen) сама решает, какой инструмент (Tool) применить — `Sentiment_Analyzer` или `Text_Summarizer`.
- **Защита от сбоев:** Использован параметр `handle_parsing_errors=True` для защиты от "галлюцинаций парсинга" (когда LLM забывает формат JSON).
- **Стек:** Использованы актуальные пакеты `langchain` и `langchain_ollama` (модель `ChatOllama` с поддержкой `bind_tools`).
